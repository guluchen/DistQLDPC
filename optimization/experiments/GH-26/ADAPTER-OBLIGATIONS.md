One-to-one mapping, mapped base-false count exactly falseLits.size, old K member membership/base-unassigned and component-weight sum exactly nbConfl are mandatory. 3. Obtain only active bound-valid hard clauses, including binary and long watcher clauses, deduplicated CRefs, excluding removed clauses. Root units are included in base facts; deleted clauses or stale CRefs must never enter a snapshot. Copying existing alpha trail MUST stop at trailRecord; the trailing positive lookahead assumptions are not permanent base facts.
4. A failure returns into the existing gap1 quasi-soft hardening path unchanged. Instrument tests for nonzero fixed/derived offsets, later root transfer, total-bound tightening, relaxation/restart, and final d/lb/ub/objective/timeout semantics. Source intention alone does not discharge these obligations.
