## Root offset identity is an explicit caller witness

The original reader's `(level0 && absent current falseLits)` condition was insufficient to self-certify a transferred objective. Baseline solve6574–6599 removes initial root-assigned soft literals from the normalized allSoftLits and sets fixedCostBySearch from their false count; solve6623 then clears falseLits. A later successful-bound transition6785–6802 cancels to root, adds remaining root falseLits.size to fixedCostBySearch and clears that list while allSoftLits can retain those objective identities. The scalar does not preserve their historical identities.

The revised test reader requires OffsetWitness: authenticated initial fixed scalar from normalization plus DISTINCT root objective identities captured BEFORE each actual root transfer/clear. It requires the scalar sum to equal current fixedCostBySearch, each witnessed objective to be currently root-false and absent current falseLits, and every excluded normalized root falsity to belong to that witness. Level0 alone no longer permits exclusion. The fixture captures its witness before executing the same scalar-add/list-clear transaction; original versus residual-plus-fixed equality is then checked on every hard-feasible truth model. Authentication of the witness at the actual production boundaries remains unimplemented; passing arbitrary historical literals is not a certificate. Initial preprocessing offsets removed from allSoftLits remain an external normalization proof obligation; no total-objective formula is inferred from fixed scalar alone.
