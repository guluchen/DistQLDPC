It records a reviewable package/runtime/probe plan only. Enabling actual setup requires separately implementing/reviewing a guarded bounded oneCPU supervisor, freezing actual support/URL and receiving named host assignment. This limitation is explicit; no readiness claim about executed setup.

Preserved E004 runtime must remain unchanged. Future isolated compiler-overlay extraction or own-prefix installer must resolve entire dependency closure, retain licenses and prevent out-of-prefix links/writes, global PATH/power/system installation or replacing original scientific runtime.
