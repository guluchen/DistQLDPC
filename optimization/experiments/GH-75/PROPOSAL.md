## PI approval
On 2026-10-09 the PI answered "可以改" ("may change") to the escalation listing the CSS X/Z
split (#71) and code-automorphism symmetry breaking (#67-C/#69/#71-C/#73-C). This
experiment is the latter. It adds one hard clause to the MaxCDCL joint encoding; the
distance definition, Pauli weight, CSS/logical-operator semantics, output format, timeout
and bound semantics stay unchanged.

## Three proposals (exactly one selected)

| ID | Mechanism | Status |
|----|-----------|--------|
| GH-75-A | Orbit-representative clause from verified code automorphisms (plain and XZ-dual) | **SELECTED** |
| GH-75-B | Lex-leader symmetry-breaking predicates for the verified generators | unselected (follow-up if A positive) |
| GH-75-C | Native GF(2) Gauss-Jordan reasoning in the engine instead of Tseitin XOR chains | unselected (large engine change) |

Ranking rationale: A is small (application code only), provably optimum-preserving, and
targets the BB/GB/LP families whose group-algebra structure gives large automorphism
groups. B breaks more symmetry but costs O(n) auxiliaries/clauses per generator and its
interaction with core-based LB and cardinality encodings is unknown. C is a multi-week
engine change with high correctness risk.

## Encoded problem and soundness argument

Encoded feasible set (baseline `build_stabilizer_instance`):
F = {(x,z) in GF(2)^n x GF(2)^n : Hz x = 0, Hx z = 0, (Gx x != 0 or Gz z != 0)},
objective |supp x U supp z| (soft unit clauses -w_i, w_i <-> x_i v z_i). Note
{x : Hz x = 0, Gx x = 0} = ker[Hz;Gx] and similarly for z.

For a qubit permutation pi (acting on vectors by coordinate permutation; dot products are
preserved, so pi(ker M) = ker pi(M) where pi(M) permutes columns):

* **Plain automorphism**: pi(rs Hx) = rs Hx, pi(rs Hz) = rs Hz, pi(rs[Hz;Gx]) = rs[Hz;Gx],
  pi(rs[Hx;Gz]) = rs[Hx;Gz]. Then (x,z) -> (pi x, pi z) is a bijection of F preserving
  the objective.
* **XZ-dual automorphism**: pi(rs Hx) = rs Hz, pi(rs Hz) = rs Hx, pi(rs[Hz;Gx]) = rs[Hx;Gz],
  pi(rs[Hx;Gz]) = rs[Hz;Gx]. Then (x,z) -> (pi z, pi x) is a bijection of F, and the support
  is moved by pi, so the objective is preserved.

Each equality is verified in the binary: pi(rs A) subset rs B by reducing every permuted
row of A against a reduced row-echelon basis of B, plus rank(A) = rank(B) (equality of
dimensions makes the inclusion an equality). Nothing is assumed from code names. Checking
the [H;G] spaces makes the argument hold for the encoded problem even if a data file were
not a perfect logical basis; for correct data rs[Hz;Gx] = ker Hx and rs[Hx;Gz] = ker Hz.

Let G be the group generated by the verified maps; every element acts on F as a bijection
that preserves the objective and moves supports by the underlying qubit permutation. Let
O_1..O_k be the orbits of G on qubits and r_j = min O_j. Every optimum (x,z) has nonempty
support; take q in the support, q in O_j and g in G with g(q) = r_j; g(x,z) is feasible,
optimal and has w_{r_j} = 1. Therefore adding the hard clause (w_{r_1} v ... v w_{r_k}):

* keeps the optimum equal to d (min over a subset that still contains an optimum);
* keeps every emitted UB sound (each constrained solution is in F);
* keeps every emitted LB sound (LB of the constrained optimum, which equals d).

If G is transitive the clause is the unit w_{r_1}. If no nontrivial map is verified
(k = n) no clause is added (it would equal the existing "P != 0" condition on w).

## Candidate generators (generic, cheap, verified)

For every divisor L of n (1 < L < n), with blocks of size L:
1. block-cyclic shift: i -> blk(i)*L + ((i mod L) + 1) mod L (contiguous blocks);
2. strided shift: with B = n/L blocks interleaved, i -> ((i div B + 1) mod L)*B + (i mod B);
3. 2D translations for every factorisation L = l*m (l,m > 1) inside contiguous blocks:
   (a,b) -> (a+1,b) and (a,b) -> (a,b+1) with local index a*m+b.
For n even, two halves of size h = n/2:
4. block swap L_g <-> R_g;
5. swap + group inverse L_g <-> R_{-g} for the cyclic group Z_h and for every Z_l x Z_m
   factorisation of h (BB/GB ZX-duality).
Each candidate is tested both as plain and as XZ-dual automorphism. Only verified maps
become generators. Orbits by union-find over generator cycles.

## Implementation scope

`src/core/distqldpc.cc` only: GF(2) bit-packed RREF/membership, candidate generation,
verification, orbit computation, the clause in the MaxCDCL solve path (added inside
`build_stabilizer_instance` before `eliminate`, only when the caller passes orbit
representatives). `-no-symbreak` restores the baseline encoding (byte-identical search
expected); `-symbreak-report` prints generators/orbits and exits without solving; `-v`
logs the same in the child. Detection runs inside the forked child so it is covered by
the wall-clock limit. `-dump-wcnf/-dump-opb/-dump-only` and RoundingSat paths are
untouched (they keep the baseline encoding). No change under `src/solver/`.

## Validation (Tier0 by this agent; no timing)

1. Build with `make -j2 CXX="c++ -Wno-reserved-user-defined-literal"`, `./scripts/smoke_test.sh`.
2. `-no-symbreak -v` trace byte-identical to the baseline `-v` trace on LP_34_20_2 and
   BB_72_12_6 (OFF and default modes).
3. Per-code automorphism evidence for all 50 codes (`-symbreak-report`): generators,
   orbit count/sizes; every reported generator independently re-verified by a separate
   Python GF(2) checker (`verify_autos.py`) reading the same matrices.
4. Science sweep, 50 codes x {default, no-card, card-mto, card-sinz}, 60 s wall
   (`tier0_science.py` from GH-60, at most 2 concurrent solver processes): every completed
   candidate value equals the named distance and the baseline completed value; every
   emitted d_lb <= d <= every emitted d_ub. Any violation = REJECT and escalate.
5. Timeouts: TIMEOUT status, `s UNKNOWN`, sound bounds (covered by the sweep).
6. QDistSAT cross-repo benchmark dispatched on a one-commit branch `ci/xrepo-gh75` with
   parent 24572d6 and the candidate tree; scientific match must be YES.

Tier1/Tier2 timing is run only by the coordinating agent with the unchanged GH16 judge.
Expected cases: large gains possible on BB/GB/LP (transitive or 2-orbit groups),
neutral on codes without detected symmetry; heuristic perturbation may also slow cases
(#60/#69 learning). No Tier3.
