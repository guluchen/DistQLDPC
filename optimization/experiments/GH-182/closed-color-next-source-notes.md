## Refined original finite-cover design, still not implemented or accepted

A deterministic integral tree/cotree cocycle avoids searching lifts or using
an external group/distance program. This is mathematical design only; claim
and validate the next topic before implementing it.

For an independently verified orientable closed base cellulation, fix the
smallest-root/edge-ordered primal spanning tree T. The dual graph restricted
to edges outside T is connected; choose its deterministic spanning tree S.
There are E-(V-1)-(F-1)=2g leftover edges. Choose the first leftover edge e.
The dual edge e plus the unique dual-tree path in S closes a dual cycle.
Orient it with e positive, and assign to each primal edge the signed
intersection alpha with this cycle, using fixed oriented face boundaries.
All other voltages are zero. Face boundary sums are exactly zero over Z,
not just mod a selected prime: the dual cycle has zero divergence at every
face. T has no voltage and alpha(e)=1.

For any fixed cover degree q, vertices(v,t) have t in Z/q, and oriented
edge u->v lifts from(u,t) to(v,t+alpha_e). Every face closes with its original
length since its integer voltage sum vanishes. Local covering bijections
must be verified at EVERY vertex/edge/face. The fundamental primal cycle
through e and T has voltage1, so it generates Z/q and the cover is connected
for composite q too. Base orientability and three face colors pull back.
Euler characteristic multiplies by q, genus becomes q(g-1)+1. Static
face-X/face-Z CSS dimension is expected4g, but actual finite GF2 ranks and
full logicals remain mandatory; no distance follows from this design.

For the independently reconstructed g4,N240 Wythoff base, q2/5/10 would
supply N480/1200/2400 and expected k28/64/124. Together with separately
verified N240/640/1440 source-quotient cellulations this could form a useful
six-size unknown-distance closed-color ladder. No voltage, group quotient,
cellulation or matrix is yet frozen/validated here. Never replace a poor
